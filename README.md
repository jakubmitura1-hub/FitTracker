# 🏋️ Fit Tracker

Android appka na sledovanie tréningov a aktivít v kalendári.

## Čo appka robí

- **Kalendár** — klikneš na deň a zaškrtneš čo si robil
- **Tréning**: Nohy, Chrbát, Hrudník, Ramená, Biceps, Triceps, Brucho/Core, Kardio
- **Iné**: Intimita
- Farebné bodky pri každom dni v kalendári podľa toho čo si zaznamenal
- **Štatistiky**: pre každú kategóriu vidíš kedy bola posledný krát + počet za 7 a 30 dní

## Inštalácia (Android Studio)

1. Otvor priečinok `FitTracker` v Android Studio (File → Open)
2. Počkaj na Gradle sync
3. Run → Run 'app'

## Dátové úložisko

Appka ukladá všetko lokálne v telefóne (SharedPreferences) — žiadne dáta sa nikam neposielajú.
